## About

This project is organized into chapters that introduce Python fundamentals in a logical order.

- `01_introduction/` covers core syntax, comments, variables, data types, and string operations.
- `02_Operators/` explains operator categories, comparisons, and precedence.
- `03_Lists/` teaches list creation, modification, iteration, and list comprehensions.
- `04_Dictionaries/` demonstrates dictionary creation, value access, and updates.
- `exercise/` contains practical example programs for hands-on practice.

Each file is intentionally small and focused so learners can understand one topic at a time.

## Learning Outcomes

By working through this repository, you will learn:

- How to write and execute Python scripts
- How to use `print()` for program output
- How to document code with comments
- How to declare variables and use basic data types
- How to work with strings, slicing, formatting, and escape sequences
- How to use arithmetic, comparison, logical, bitwise, identity, and membership operators
- How operator precedence affects expressions
- How to create, access, modify, and iterate over lists
- How to write list comprehensions and use list methods
- How to create and use dictionaries for structured data
- How to build simple practice programs using Python fundamentals

## Usage

Open a terminal in the repository root and run any Python file with one of the following commands:

```bash
python3 01_introduction/01_first.py
```

If your system maps `python` to Python 3, use:

```bash
python 01_introduction/01_first.py
```

Example commands:

```bash
python3 02_Operators/01_arithmetic_operators.py
python3 03_Lists/01_list.py
python3 04_Dictionaries/01_dictionaries.py
python3 exercise/01_student_information_card.py
```

## Project Exercises

The `exercise/` folder contains practical examples to apply the concepts learned in the chapters.

- `01_student_information_card.py` — Builds a student information card using variables and formatted output.
- `02_cafe_bill_generate.py` — Calculates a café bill and prints the total amount.
- `bmi_calculator.py` — Demonstrates BMI calculation and output categories.

> Note: `bmi_calculator.py` currently includes BMI logic but requires `weight` and `height` variables to be defined before execution.
